# ふりろぐ クローズドテスト運用・募集案内

## 現在地

- Play Consoleの既存トラック: `クローズド テスト - Alpha`（現在は非アクティブ）
- 設定済み: 国・地域は日本のみ
- 未設定: テスター、署名済みAABの登録、リリース公開
- 募集開始前に必要: 上記3項目を設定し、Googleの審査を経てオプトインURLが有効になることを確認する

## Googleが確認する「テスト実行の証明」

Play Consoleが、クローズドテストへのオプトイン人数と継続日数を自動集計する。スクリーンショットや証明書の提出は不要。

- 対象: 2023年11月13日以降に作成された個人デベロッパーアカウントで、Play Consoleに要件が表示される場合
- 必要人数: 12人以上
- 必要期間: 各テスターがオプトインした状態を14日間連続で維持
- テスターに必要なもの: GoogleアカウントとAndroid端末
- 14日後: Play Consoleから製品版アクセスを申請し、テスト内容・反応・修正内容を記入する

## テスター向け案内文

Androidアプリ「ふりろぐ」のGoogle Playクローズドテストに協力してくださる方を募集しています。

ふりろぐは、ダンスなどの練習動画をスロー再生・フレーム送りで見返し、気づきを付箋やメモとして残すローカル動画ノートです。アカウント登録、広告、課金はありません。動画やメモは端末内だけに保存されます。

ご協力いただきたいこと:

1. 参加に使うGoogleアカウントのメールアドレスを、公開投稿への返信ではなくDMで連絡する
2. 登録完了の連絡後、Android端末で参加リンクを開いてテストへ参加する
3. Google Playからアプリをインストールする
4. 参加後14日間は、テスト参加を解除しない
5. 可能であれば、動画追加・撮影・再生・フレーム送り・付箋・メモを試す
6. 不具合や感想があれば GitHub Issues（weeder0305/furilog） へ送る

参加リンク: （クローズドテスト版を公開後に追記）

## X投稿用の短文

Androidアプリ「ふりろぐ」のクローズドテスターを募集します。練習動画をスロー再生・フレーム送りで確認し、付箋やメモを残せる無料アプリです。参加後14日間、テスト参加を解除せず、実際に操作して感想をいただける方はDMまたは GitHub Issues（weeder0305/furilog） までお願いします。参加用Googleアカウントのメールアドレスは公開返信に書かないでください。

※Alphaリリース公開後、登録済みテスターへ参加リンクを個別案内する。

## テスターから確認する項目

- Android機種名とAndroidバージョン
- 動画の追加・撮影・再生ができたか
- 音声、内外カメラ、画面回転、戻るジェスチャーに問題がないか
- 分かりにくい表示や操作がなかったか
- クラッシュ、保存失敗、記録消失がなかったか

## リリースノート案（v2.4）

Android版の初回クローズドテストです。撮影動画を端末アルバムにも残すか選べるようにし、1.5倍・2倍速再生と、トップ画面からの動画複数選択・一括削除を追加しました。動画の追加・撮影、スロー再生、フレーム送り、付箋、メモも利用できます。

## 注意

- 人数だけを水増しする偽アカウントや、実態のないテスター販売は使わない。
- 専門のテスト会社を使う場合は、実在するGoogleアカウントで参加し、実際のテストとフィードバックを提供する事業者を選ぶ。
- 14日間の途中で参加解除した人は、継続人数として不足する可能性があるため、12人ぴったりではなく15人前後を目標にする。
